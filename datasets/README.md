# Datasets

This directory is intentionally empty in the repository (physiological
datasets are large and most are PhysioNet-credentialed, so they should never
be committed to git). Download the datasets referenced in the main README
directly from their sources and point `configs/default.yaml` at the result.

## Expected layout

```
datasets/
├── ptbxl/          # PTB-XL 12-lead ECG (https://physionet.org/content/ptb-xl/)
├── mitbih/         # MIT-BIH Arrhythmia Database (https://physionet.org/content/mitdb/)
├── bidmc/          # BIDMC PPG & ECG (https://physionet.org/content/bidmc/)
├── pulsedb/        # PulseDB (https://doi.org/10.13026/2bs4-yg84 or the PulseDB GitHub release)
├── mimic_waveform/ # MIMIC Waveform Database (https://physionet.org/content/mimic3wdb/)
└── cache/          # generated by preprocessing/ -- cached .npy window arrays
                     # consumed directly by training/train.py
```

Each PhysioNet-format dataset directory should contain the standard WFDB
`.hea`/`.dat` (and `.atr` for MIT-BIH) file pairs, exactly as downloaded --
`training/dataset.py`'s loaders (`load_ptbxl_record`, `load_mitbih_record`,
`load_bidmc_record`, `load_pulsedb_record`) read this format via `wfdb`.

## Building the training cache

1. Download the raw dataset(s) above into their respective folders.
2. Run the preprocessing pipeline (filtering, R-peak/systolic-peak detection,
   ECG-PPG synchronization) over each recording using the functions in
   `preprocessing/ecg/`, `preprocessing/ppg/`, and
   `preprocessing/synchronization/`.
3. Save the resulting cleaned signal arrays (and your risk labels) as
   `datasets/cache/ecg_signals.npy`, `ppg_signals.npy`, and `labels.npy` --
   lists/object-arrays of one 1-D array per recording, matched by index.
4. Point `configs/default.yaml`'s `data:` section at these paths (already the
   default) and run `python -m training.train`.

No dataset content, real patient signals, or experimental results are
included in this repository -- everything under this directory must be
populated by you from the original, licensed sources.
